# 听见 · 盲道行 3D (`⠞⠊⠝⠛ ⠚⠊⠁⠝ · ⠍⠁⠝⠛ ⠙⠁⠕ ⠭⠊⠝⠛`)

轻量级第一人称盲人视角城市无障碍共情互动小游戏，采用 **Vite + TypeScript + Three.js + 自定义 WebGL2 HDR 多通道后处理管线 + 原生 Web Audio API + Tailwind CSS** 纯前端构建，零外部模型与音频网络依赖。

## 核心特性

- **电影级 HDR 声波视界与雨夜水洼倒影**：自定义 WebGL2 多通道后处理管线（半分辨率 SSAO、Karis 加权多级 HDR Bloom、变形镜头水平炫光、ACES/AgX 混合电影调色、FXAA 与胶片颗粒），结合实时平面水洼反射、动态雨滴涟漪与程序化云层天空 + PMREM 环境光。
- **极黑沉浸与手动节奏探杖**：未探及区域压至近乎纯黑，支持桌面端 Pointer Lock 捕捉鼠标自由转视角与移动端自动影院横屏；纯手动敲杖，单次/超时精准敲击正前方指定点，连续点击呈微幅「左一下、右一下」节奏扫探，长按可蓄力释放远距重敲声波。
- **凝神聆听与 3 处城市微光互动**：按住 `Shift` / 右键进入凝神聆听模式，通过顶部「声源方位罗盘」与声源脉冲感知环境声景；街区沿途可触发标记违停占道、轻抚街角小猫、触摸无声信号灯柱 3 处共情微互动。
- **真实牵手搀扶过街与雨后夕阳结局**：无声斑马线三次呼喊求助后，对街信号灯转绿，热心路人迎面走来与第一人称左手实时牵手并肩过街，抵达安全区后整条雨后十字路口沐浴金色晚霞。
- **盲汉互译无障碍 UI 与共情分享卡**：提供画质预设（低/中/高/极高）、高对比度模式、声波停留时长（`1.5s / 2.5s / 4.0s`）、浏览器原生语音朗读（`speechSynthesis`）及离屏 `<canvas>` 本地生成的 9:16 竖版公益共情海报。

## 本地开发与构建

```bash
npm install
npm run dev
npm run build
```
